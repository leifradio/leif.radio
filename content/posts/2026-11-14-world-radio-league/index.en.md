I've had a World Radio League (WRL) subscription for a year or so, but I haven't used it much lately.

What I've been using instead is Log4OM, which is very good and has lots of features, of which I probably only use some. Unfortunately Log4OM only runs on Windows, and I like to use other operating systems, at least sometimes. WRL runs in the browser (there's also a desktop app, but only for Windows), so it doesn't matter which operating system you use.

Since I hadn't used WRL for a while, I went through the settings to see what's new and might need configuring. I adjusted the QRZ.com sync so it points to my new callsign SM4T, and I'm also considering making it automatic and perhaps adding LoTW sync as well. Otherwise I didn't change anything; if something needs doing, I'll find out once I start logging QSOs.

{{< figure src="qso-karta.jpg" alt="WRL map of SM4T's QSOs with band, mode and DXCC statistics" caption="My QSOs as SM4T in WRL: 242 QSOs, all on CW" >}}

WRL is good. It keeps evolving, and the people behind it are very active on YouTube, among other places, explaining how WRL works, showing new features and asking for feedback. I like that!

Now I'll try it for a few weeks and see how it feels this time.
